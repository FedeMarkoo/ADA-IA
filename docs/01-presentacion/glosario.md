# 1.4 Glosario

- **Router:** clasifica el pedido y propone acción, tarea y complejidad.
- **Selector:** resuelve el modelo permitido para ese pedido.
- **MCP:** servidor de herramientas expuesto mediante Model Context Protocol.
- **Context packet:** paquete acotado de resumen, mensajes recientes y memorias relevantes.
- **Refiner:** proceso que extrae conocimiento, depura y compacta memoria.
